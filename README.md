# Voice-Based AI Gym Workout Coach 🎙️💪

An autonomous, voice-only gym coach web app designed for mid-workout hands-free guidance. Built for hackathon demonstration with instant interruption (barge-in) and state-synchronized audio recovery powered by Rime TTS.

## Key Features
- **Hands-Free Rep Counting & Rest Timers**: Clear pacing and guidance.
- **Instant Voice Barge-In / Interruption**: Speak anytime ("skip rest", "pause", "next set") to instantly stop audio (<50ms) and synchronously update internal state.
- **Rime.ai TTS Engine**: Natural, low-latency synthesized speech.
- **Zero-Friction STT**: Browser-native Web Speech API with real-time interim recognition.
- **Visual Gym HUD**: Real-time workout metrics and barge-in event logging for validation.
